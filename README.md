E-Commerce

A React and TypeScript e-commerce frontend, built with Vite. The project is set up as the client side of a MERN stack store — this repo currently holds the frontend application.

Tech stack
React 19 with TypeScript
Vite for the build and dev server
Tailwind CSS for styling
Redux Toolkit and Zustand for state management
React Router for navigation
Axios for API requests
Radix UI primitives (dialog, select, slider, tooltip) for accessible UI components
Framer Motion for animations
Recharts for charts and data visualization
React Hot Toast for notifications
Project structure
e-commerce/
├── public/     Static assets
├── src/        Application source code
└── index.html  Entry HTML file
Getting started

Clone the repository:

git clone https://github.com/muhammadsajjad381/e-commerce.git
cd e-commerce

Install dependencies:

npm install

Run the development server:

npm run dev

Build for production:

npm run build

Preview the production build:

npm run preview
Status

Frontend is in progress. Backend (Node/Express/MongoDB) is not part of this repo yet and will be added separately.
